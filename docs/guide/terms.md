## 1. 软件定义、权属与使用许可

### 1.1 软件定位

VoxVer Launcher 是一款面向 Minecraft Java 版的**非官方本地客户端启动工具**，基于 XMCL 启动核心，使用 Electron + Vue3 + TypeScript 构建。具备游戏版本管理、Fabric / Forge / NeoForge / Quilt ModLoader 一键安装、Modrinth 模组资源下载、游戏崩溃智能分析、HMCL/PCL2 实例导入、WebRTC P2P 实例分享、微软账号登录、离线游玩等功能。本项目**正在开发联机隧道能力**，该能力仅提供联机功能的入口与连接配置工具，帮助玩家自行搭建联机链路；**本软件不提供、不运营任何联机所需的中继服务器**，中继服务器与网络环境需由玩家自行准备、配置和搭配。

**本软件仅提供客户端启动、实例分享以及联机功能的工具入口，不提供任何联机中继服务器。我们不运营、不托管、不参股、不代运营任何永久性 Minecraft 游戏服务器。** 所有您在启动器内连接的第三方独立服务器，均为完全独立的第三方主体运营，不受我们控制、管理。

当前正式支持 Windows 10+ x64；macOS、Linux 版本尚在计划开发，尚未正式发布。CurseForge 资源平台接入、联机隧道能力均为开发中的规划功能，暂未上线。

## 5. 第三方资源、接口、P2P 实例分享与联机隧道说明

- **游戏版本下载（BMCLAPI）**：本启动器使用 BMCLAPI 镜像源获取 Minecraft 版本文件，BMCLAPI 为第三方镜像服务，我们不对镜像文件完整性、版权做担保；
- **Mod 资源（Modrinth API）**：模组搜索下载来源于 Modrinth 平台，模组版权归各个模组作者，下载模组即表示您同意 Modrinth 平台服务条款；CurseForge 接入尚在计划；
- **加载器元数据**：Fabric / Forge / NeoForge / Quilt 的元数据来自对应官方开放 API；
- **微软账号登录**：使用微软 Device-Code Flow 设备码认证，身份校验完全由微软服务完成，我们不会获取、存储您的微软账号密码；
- **WebRTC P2P 实例分享（6 位分享码）**：该功能基于 WebRTC 点对点直连。实例模组、配置文件在**用户与用户设备之间直接传输，文件数据流不经过我方服务器**。您开启分享、接收他人分享的实例文件，风险完全由您自行承担，请自行校验收到文件安全性。我们不对其他用户通过 P2P 传给您的文件承担安全、合规责任。
- **联机隧道能力（开发中）**：本软件仅提供联机功能的入口与连接配置工具，**不提供任何中继服务器**。玩家需自行准备、配置并搭配中继服务器或网络转发环境，游戏数据经玩家自行配置的服务传输，我们无法也不对其进行解析、存储或审核。联机房间的访问权限由房主控制。我们不做内容审核，不对房间内玩家言行、交易、纠纷负责。

以上全部第三方服务以及规划功能拥有独立的用户协议与风险规则，我们不对第三方服务的可用性、安全性、内容合规承担连带责任。
