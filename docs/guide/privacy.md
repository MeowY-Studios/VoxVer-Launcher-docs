在使用本软件前，请仔细阅读本声明。您启动、使用本软件，代表您充分知晓并同意本隐私声明约定的数据处理规则。若您不同意本声明内容，请不要使用本软件。

## 1. 本启动器默认不会主动收集、上传个人信息

本软件定位为**本地 Minecraft 客户端启动工具**，我们没有部署用于静默采集用户信息的后台服务。在您没有主动触发操作的前提下：

- 不会自动读取、上传您的姓名、手机号、身份证、家庭地址等身份信息；
- 不会静默读取电脑里其他无关文件夹、文档、图片；
- 不会后台抓取剪贴板、浏览器记录、聊天记录；
- 不会持续上报设备序列号、硬件识别码、地理位置等设备信息。

所有游戏配置、登录缓存、本地存档、模组、实例数据全部保存在您当前使用设备的本地磁盘中。我们不远程备份、不主动同步、不私自读取这些本地文件。

## 2. 用户主动操作才会触发的网络请求

只有当您主动点击对应功能时，启动器才会发起网络请求，请求目的仅为完成您选择的功能：

- **游戏版本、资源下载（BMCLAPI）**：向 BMCLAPI 镜像源请求游戏版本元数据与游戏文件；
- **Mod 模组下载（Modrinth）**：调用 Modrinth 开放 API，搜索、下载模组、资源包；模组文件与元数据由 Modrinth 平台提供；
- **ModLoader 元数据**：向 Fabric、Forge、NeoForge、Quilt 官方接口获取加载器版本信息；
- **微软账号登录**：采用 Device-Code Flow 设备码认证，跳转至微软官方身份验证服务，账号校验流程由微软负责；账号凭证不会发送给我们；
- **版本更新检查**：访问 GitHub Releases 获取启动器更新信息；仅传递基础访问日志（访问时间、访问 IP），不会绑定您的身份；
- **实例 P2P 分享（WebRTC）**：使用 6 位分享码进行实例传输时，**实例文件直接在两台用户设备之间点对点传输，游戏实例、模组、配置数据流不会经过我方服务器**。信令交换仅用于建立 P2P 连接，不会存储您的实例文件。您需要自行校验接收到文件的安全性；
- **联机隧道能力（开发中）**：本软件仅提供联机功能的入口与连接配置能力，**不提供、不运营任何中继服务器**。中继服务器或网络转发环境需由玩家自行准备与配置，联机链路及数据传输由玩家自行配置的服务完成。我们既不接入也不转发游戏数据，不解析、不存储任何游戏内聊天或世界数据。
- **服务器列表加载**：若您加载第三方服务器列表，列表数据由第三方提供，相关服务器信息由第三方维护。

以上请求，您都可以选择不使用对应功能，从而避免发起对应网络访问。

## 3. 本地存储与缓存

### 3.1 本地缓存数据

启动器会在本地写入必要缓存，用于提升使用体验：游戏版本索引、服务器地址、您手动填写的配置、资源缓存、游戏实例、联机房间历史记录。这些数据仅保存在本机，仅本软件自身读取。卸载本软件、手动删除启动器目录，即可清除全部本地缓存。

### 3.2 Cookie 和本地存储

本软件桌面客户端本身不使用网页 Cookie。如果软件内置网页组件（登录、公告页面），网页组件由对应第三方站点自行管理 Cookie，遵循对应站点隐私政策，不受我们控制。

## 6. 第三方服务清单

本软件在使用过程中，可能对接以下类型第三方服务，它们各自独立处理数据：

- Microsoft 账户身份验证服务：适用微软隐私声明；
- BMCLAPI：Minecraft 版本国内镜像服务；
- Modrinth API：模组资源平台；CurseForge 接入尚属于开发计划；
- Fabric / Forge / NeoForge / Quilt 官方元数据接口；
- GitHub Releases：启动器版本分发托管；
- 第三方 Minecraft 服务器：独立运营，规则自定；
- WebRTC 底层 P2P 组件：用于用户之间实例直传，文件不经过我方服务器；
- 联机隧道能力（开发中）：本软件不提供中继服务器，玩家自行配置的中继服务由相应提供方独立运营，我们不参与、不存储游戏内容。

我们不对第三方服务的数据安全、内容合规、收费行为承担连带责任。下载第三方模组、实例文件、加入联机房间风险由用户自行承担。

绝大多数数据都存储在您本地电脑，数据安全主要由您负责：妥善保管电脑、账号，不要随意分享本地配置文件；接收 P2P 分享实例务必确认来源可信；加入联机房间请辨别其他玩家身份，谨慎进行任何私下交易。

我们在有限的服务端日志（更新访问日志等）中，会尽量缩短日志保留周期，日志仅用于排查故障、统计访问量，不会用于用户画像、广告推送。联机功能不经过我方服务器，我们不保留任何联机会话日志。
